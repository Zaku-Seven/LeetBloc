# Leetbloc

Paste a LeetCode link. Gemma 4 turns the problem into two Scratch-style puzzles, a brute-force solution and an optimized one. Snap the blocks together, submit, and keep your progress.

The design is in [DESIGN.md](./DESIGN.md). The database schema and data flow are in [DATABASE.md](./DATABASE.md).

The home page is a desktop Three.js board. Two Sum can be snapped together there. Phone layout and sound are later.
